Android APK Build & Installation

LUMIQ AI includes a reproducible GitHub Actions CI pipeline (.github/workflows/android-apk.yml) that runs unit tests, builds app-debug.apk, and publishes the downloadable LUMIQ-AI-APK artifact on every push or manual workflow dispatch.

  1. Open GitHub repository → Actions → Build LUMIQ AI Android APK.
  2. Download the LUMIQ-AI-APK artifact and unzip app-debug.apk.
  3. On Android, open the APK, allow Install unknown apps if prompted, and tap Install.
