## Overview
LUMIQ AI is a 10D Pearl-Glass Android AI Operating Layer built with **Kotlin**, **Jetpack Compose**, **Material 3**, **Firebase AI Logic (Gemini)**, **Firebase App Check**, **Credential Manager Google Sign-In**, and **Cloud Firestore**.

## Core Capabilities
- **10D Interactive Neural Orb & Pearl-Glass UI**: Custom Jetpack Compose Canvas Orb (`LumiqOrbCanvas`), electric-blue / cyan glow accents, light Pearl-Glass and Obsidian Dark themes.
- **Zero-Key Gemini Streaming**: `gemini-3.5-flash-lite` (ultra-fast voice/reply mode), `gemini-3.8-flash` (default), and `gemini-4-argon` (deep reasoning) authenticated via Firebase App Check, plus encrypted OpenAI/Groq/Custom HTTP providers.
- **5-Agent Parallel Workspace**: Concurrent `Semaphore(5)` execution across Coding, Research, Browser, Phone Assistant, and WhatsApp Assistant agents + custom agent builder & Emergency Stop.
- **LUMIQ Voice Studio**: Android `SpeechRecognizer` (Hindi, English India/Hinglish, US/UK), wake word filtering, curated TTS voice profiles, echo gating, and Foreground Mic Service.
- **Hardened WebView Browser**: Multi-tab browsing with HTTPS upgrades, Google/DuckDuckGo/Bing, bookmarks, and AI page summarization.
- **Code Studio & Termux Bridge**: Multi-file syntax editor + AI debugging + HTML preview + ZIP export + `com.termux.RUN_COMMAND` integration.
- **Website & Android App Studios**: AI HTML5 site builder with responsive preview + Netlify deployment, and Jetpack Compose Android project generator + GitHub Actions CI APK builder.
- **Vision & Documents**: CameraX live capture, zero-permission Android Photo Picker, SAF PDF/TXT reader, on-device ML Kit OCR & QR scanning, and multimodal Gemini Q&A.
- **Phone Control & WhatsApp Assistant**: Explicit user-triggered Accessibility actions, hardware controls, Default Digital Assistant role support, and confirmation-gated WhatsApp drafts (`Drafted` -> `Opened` -> `Sent Confirmed`).
- **App Lock & Keystore Vault**: Salted PBKDF2-SHA256 PIN lock + BiometricPrompt + AES-256-GCM Password Vault with 30s clipboard auto-clear.
- **Public Website & LUMIQ LABS Admin Console**: Located in `/web/public/` and `/web/public/admin/`.
